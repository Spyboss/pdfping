Why PDFPing Exists

HTML-to-PDF APIs get expensive for hobby projects. Running Chromium yourself adds operational overhead: memory leaks, Docker images, version upgrades.

This is a free, open-source alternative. Use the hosted instance or self-host your own.

Who This Is For
  • Side projects
  • Hackathons
  • Open source software
  • Internal tools
  • Learning APIs
If you need enterprise compliance or hundreds of thousands of production documents per month, a commercial platform is a better fit.
How It Works
HTML or URL POST /api/v1/convert → PDF

One endpoint. POST HTML or a URL. Get a PDF back. Try it in the playground.

API Examples
curl (authenticated) 
curl -X POST https://pdfapi.uhadev.com/api/v1/convert \
  -H "Authorization: Bearer pdfping_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "html": "<h1>Hello World</h1>", "options": { "format": "A4" } }' \
  -o output.pdf
JavaScript (fetch) 
// Node.js or browser
const res = await fetch('https://pdfapi.uhadev.com/api/v1/convert', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer pdfping_YOUR_KEY'
  },
  body: JSON.stringify({
    html: '<h1>Hello World</h1>',
    options: { format: 'A4' }
  })
});
const blob = await res.blob();
TypeScript (fetch) 
// Node.js with TypeScript
import { writeFileSync } from 'fs';

const res = await fetch('https://pdfapi.uhadev.com/api/v1/convert', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer pdfping_YOUR_KEY'
  },
  body: JSON.stringify({
    html: '<h1>Hello World</h1>',
    options: { format: 'A4' }
  })
});

const buffer = Buffer.from(await res.arrayBuffer());
writeFileSync('output.pdf', buffer);
Python (requests) 
# pip install requests
import requests

res = requests.post(
  'https://pdfapi.uhadev.com/api/v1/convert',
  headers={
    'Authorization': 'Bearer pdfping_YOUR_KEY',
    'Content-Type': 'application/json'
  },
  json={
    'html': '<h1>Hello World</h1>',
    'options': { 'format': 'A4' }
  }
)

with open('output.pdf', 'wb') as f:
  f.write(res.content)

FAQ

Does JavaScript execute?

Yes. Chromium runs JavaScript before generating the PDF. Use the wait option for JS-rendered content.

Can I self-host?

Yes. The project is MIT licensed. Clone the repo, run docker compose up, and run your own instance.

Are custom fonts supported?

Yes. Chromium loads web fonts. Include them in your HTML via @font-face or Google Fonts.

Can I set page size or margins?

Yes. Pass options.format (A4, Letter, etc.), options.landscape, and options.margin in the request body.

Is authentication required?

No. The /public endpoint works without a key (50 conversions/day/IP). For higher limits, sign up for a free API key.

How do I get an API key?

Sign up with email or Google. A key is created automatically. No credit card required.
