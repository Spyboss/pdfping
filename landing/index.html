HTML to PDF. One HTTP request.

Send HTML or a URL, get a PDF back. Chromium renders CSS, fonts, images, JavaScript.

curl 
curl -X POST https://pdfapi.uhadev.com/api/v1/convert/public \
  -H "Content-Type: application/json" \
  -d '{ "html": "<h1>Hello World</h1>" }' \
  -o output.pdf

No API key required. 50 conversions/day per IP. Sign up for a free key. 10,000 conversions/month.

Why PDFPing Exists

HTML-to-PDF APIs get expensive for hobby projects. Running Chromium yourself adds operational overhead: memory leaks, Docker images, version upgrades.

This is a free, open-source alternative. Use the hosted instance or self-host your own.

FAQ
How do I convert HTML to PDF?
Send a POST request to https://pdfapi.uhadev.com/api/v1/convert/public with your HTML in the request body. No API key required. For higher limits, sign up for a free key and use the authenticated endpoint.
Is PDFPing free?
Yes. The public endpoint allows 50 free conversions per day per IP. You can also sign up for a free API key with a usage dashboard. Paid plans start at $9/month for 500 conversions. The source code is MIT licensed.
Does it support CSS and web fonts?
Yes. PDFPing uses a full Chromium instance for rendering. All modern CSS features including Grid, Flexbox, custom fonts, and animations work exactly as they would in a browser.
Can I self-host?
Yes. The entire project is MIT licensed on GitHub. It runs on Node.js with Playwright. Use the Dockerfile for easy deployment.
