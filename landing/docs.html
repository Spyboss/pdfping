API Reference

Convert HTML or URLs to PDF with a single POST request. Chromium renders CSS, fonts, images.

Quick Start

curl (no API key) 
curl -X POST https://pdfapi.uhadev.com/api/v1/convert/public \
  -H "Content-Type: application/json" \
  -d '{ "html": "<h1>Hello World</h1>" }' \
  -o output.pdf
Free API key: Sign in to get an API key with a 10,000 conversion limit. No credit card required.

Authentication

Authenticated requests use a Bearer token in the Authorization header. Get your key by signing up.

Authorization: Bearer pdfping_<your_api_key>

Without a key, use the /public endpoint. Limited to 50 conversions per day per IP.

Endpoints

POST /api/v1/convert Authenticated conversion

Requires a valid API key. Supports all options including custom page format, margins, and landscape. Counts toward your API key usage limit.

POST /api/v1/convert/public Public conversion (rate-limited)

No API key required. Limited to 50 conversions per day per IP address.

Request Parameters

Send a JSON body with Content-Type: application/json.

ParameterTypeDefaultDescription
htmlstring-HTML string to render. Provide this or url.
urlstring-URL to render. Provide this or html.
options.formatstringA4Page format. A3, A4, A5, Letter, Legal, Tabloid.
options.landscapebooleanfalseRender in landscape orientation.
options.printBackgroundbooleantrueInclude CSS background colors and images.
options.marginstring0mmPage margin (CSS units, e.g. 10mm, 0.5in). Applied to all sides.
options.waitnumber1Seconds to wait after page load before generating PDF. Increase for JS-rendered content.

Example request body

{
  "html": "<h1>Invoice</h1><p>Hello</p>",
  "options": {
    "format": "A4",
    "landscape": false,
    "margin": "10mm"
  }
}

Responses & Errors

Success (200)

Returns the PDF binary with Content-Type: application/pdf. The Content-Disposition header is set to inline so browsers display the PDF directly.

Error responses

StatusBodyCause
400{ "error": "..." }Missing or invalid request body
401{ "error": "..." }Missing Authorization header
403{ "error": "..." }Invalid API key
429{ "error": "..." }Rate limit exceeded
500{ "error": "...", "detail": "..." }Conversion failed (invalid HTML, unreachable URL, browser error)

Code Examples

curl

curl (authenticated with options) 
curl -X POST https://pdfapi.uhadev.com/api/v1/convert \
  -H "Authorization: Bearer pdfping_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "html": "<h1>Hello World</h1>",
  "options": { "format": "A4", "margin": "10mm" }
}' \
  -o output.pdf

Fetch API

Node.js with fetch 
// Node.js
const res = await fetch('https://pdfapi.uhadev.com/api/v1/convert', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer pdfping_YOUR_KEY',
  },
  body: JSON.stringify({
    html: '<h1>Hello World</h1>',
  }),
});
const buffer = Buffer.from(await res.arrayBuffer());
require('fs').writeFileSync('output.pdf', buffer);
Node.js with fetch (TS) 
// Node.js with TypeScript
import { writeFileSync } from 'fs';

const res = await fetch('https://pdfapi.uhadev.com/api/v1/convert', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',

  },
  body: JSON.stringify({
    html: '<h1>Hello World</h1>',
  }),
});

const buffer = Buffer.from(await res.arrayBuffer());
writeFileSync('output.pdf', buffer);

Python (requests)

Python (requests) 
# pip install requests
import requests

res = requests.post(
  'https://pdfapi.uhadev.com/api/v1/convert',
  headers={
    'Authorization': 'Bearer pdfping_YOUR_KEY',
    'Content-Type': 'application/json',
  },
  json={
    'html': '<h1>Hello World</h1>',
    'options': { 'format': 'A4' },
  },
)

with open('output.pdf', 'wb') as f:
  f.write(res.content)

SDKs & Clients

NPM package

npm package: pdfping-api 
# npm install pdfping-api
import { PDFPing } from 'pdfping-api';

const client = new PDFPing('pdfping_YOUR_KEY');

const pdf = await client.convert({
  html: '<h1>Hello World</h1>',
  options: { format: 'A4' },
});
require('fs').writeFileSync('output.pdf', pdf);
npm package: pdfping-api (TS) 
# npm install pdfping-api
import { PDFPing } from 'pdfping-api';
import { writeFileSync } from 'fs';

const client = new PDFPing('pdfping_YOUR_KEY');

const pdf = await client.convert({
  html: '<h1>Hello World</h1>',
  options: { format: 'A4' },
});

writeFileSync('output.pdf', pdf);
